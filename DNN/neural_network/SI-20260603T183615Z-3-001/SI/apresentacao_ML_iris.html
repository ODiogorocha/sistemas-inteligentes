Pré-processamento

Imputação, codificação, normalização e divisão treino/teste

🧹 Etapas Aplicadas

  • SimpleImputer (mean) — cobre possíveis NaN em dados reais; substitui pela média da coluna
  • LabelEncoder — converte classes texto → inteiro (0,1,2)
  • StandardScaler — z-score: subtrai média, divide pelo desvio padrão
  • train_test_split — 80% treino / 20% teste, estratificado

❓ Por que StandardScaler?

  • MLP e SVM são sensíveis à escala das features
  • Gradiente descende uniformemente em todas as dimensões
  • MinMaxScaler seria afetado por outliers
  • RobustScaler seria indicado se houvesse muitos outliers

Otimização com Optuna

Busca automática dos melhores hiperparâmetros da MLP

📌 O que é Optuna? Framework de otimização bayesiana que executa múltiplos "trials", cada um com uma combinação de hiperparâmetros diferente. Aprende dos trials anteriores para focar nas regiões mais promissoras do espaço de busca.

Optuna import optuna def objective(trial): # Optuna sugere hiperparâmetros a cada trial n_layers = trial.suggest_int('n_layers', 1, 3) units_l1 = trial.suggest_categorical('units_l1', [32, 64, 128]) activation = trial.suggest_categorical('activation', ['relu', 'tanh']) lr = trial.suggest_float('lr', 1e-4, 1e-2, log=True) dropout = trial.suggest_float('dropout', 0.0, 0.5) # Constrói e treina o modelo com os hiperparâmetros do trial model = build_model(units_l1, activation, dropout, lr) history = model.fit(X_train, y_train, validation_split=0.2, epochs=100, verbose=0) return min(history.history['val_loss']) # Optuna minimiza este valor # Cria e executa o estudo com 30 trials study = optuna.create_study(direction='minimize') study.optimize(objective, n_trials=30) print(study.best_params) # melhor combinação encontrada print(study.best_value) # melhor val_loss

Regularização & Overfitting

Análise do comportamento da rede e aplicação de técnicas de regularização

Sem Regularização

  • Rede grande: 256 → 256 → 128
  • Sem dropout, sem L2
  • Treina 200 épocas completas
  • Gap treino-validação alto
  • ⚠ Overfitting evidente

Com Regularização

  • Mesma arquitetura (256 → 256 → 128)
  • Dropout 30% após cada camada
  • Weight Decay L2 (λ=0.001)
  • Early Stopping (patience=20)
  • ✅ Melhor generalização

💡 Como cada técnica funciona

TécnicaComo funcionaEfeito
Dropout (0.3) Zera 30% dos neurônios aleatoriamente por batch Reduz co-dependência → generaliza melhor
L2 / Weight Decay Penaliza pesos grandes na função de perda Pesos menores → modelo mais simples
Early Stopping Para quando val_loss para de melhorar por N épocas Evita treinar além do ponto ótimo
Redução de Rede Menos neurônios/camadas → menos parâmetros Menos capacidade de memorizar o treino
Keras – Regularização from tensorflow.keras import regularizers from tensorflow.keras.callbacks import EarlyStopping model_reg = keras.Sequential([ layers.Input(shape=(input_dim,)), layers.Dense(256, activation='relu', kernel_regularizer=regularizers.l2(0.001)), # L2 layers.Dropout(0.3), # desativa 30% dos neurônios por batch layers.Dense(256, activation='relu', kernel_regularizer=regularizers.l2(0.001)), layers.Dropout(0.3), layers.Dense(128, activation='relu'), layers.Dense(3, activation='softmax') ]) # Early Stopping: para se val_loss não melhorar por 20 épocas early_stop = EarlyStopping( monitor='val_loss', patience=20, restore_best_weights=True # reverte para melhor checkpoint ) model_reg.fit(X_train, y_train, validation_split=0.2, epochs=200, callbacks=[early_stop])
✅ Resposta às perguntas do trabalho:

• A rede apresentou overfitting sem regularização (gap treino-val elevado)
• Técnicas usadas: Dropout + L2 + Early Stopping
• Regularização melhorou a generalização no conjunto de teste
• Early Stopping foi a estratégia mais eficiente em custo/benefício
